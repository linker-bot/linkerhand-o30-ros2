# HOP 触摸传感器读取流程说明

本文说明通过 HOP 协议读取触摸传感器描述和实时数据的推荐流程。

## 1. 读取传感器类型

先读主索引 `0x31` 的传感器描述区，判断当前是否配置了传感器。

读 `0x31/0x00` 可得到传感器类型字符串：

- `NO_SENSOR`：无传感器
- `TASHAN_GATHER`
- `HUAWEIKE`
- `FULAI`
- `TSSP_GENGLE`
- `TSSP_JZG`

如果返回 `NO_SENSOR`，后续 `0x32~0x34` 没有有效触摸数据。

## 2. 选择读取区域

写 `0x31/0x6E` 选择要读取哪个传感器区域：

- `1`：大拇指
- `2`：食指
- `3`：中指
- `4`：无名指
- `5`：小拇指
- `6`：手掌

如果选择了不存在的区域，例如没有手掌传感器但写了 `6`，描述长度和数据长度可能返回 `0`，表示没有该区域数据。

## 3. 读取最大行列

读 `0x31/0x29` 和 `0x31/0x2A` 获取当前选择区域的最大行列：

- `row_max = 0 && column_max = 0`：表示该传感器不是点阵类数据，或者当前区域没有点阵。
- 行列非 `0`：表示有点阵数据。

## 4. 读取有效点 mask

如果想知道点阵哪些位置有效，先写：

```text
0x31/0x71 = 1
```

这个模式叫“有效点 mask 模式”。

写 `0x71` 后，必须重新读取：

- `0x31/0x2B`：描述符长度
- `0x31/0x2C`：描述符
- `0x31/0x6C`：数据总长度

然后再读取 `0x32~0x34`。此时得到的不是压力值，而是点阵有效性：

- `1`：该点是有效点
- `0`：该点是无效点

这个步骤主要用于上位机绘制传感器有效点分布图。

## 5. 切回真实数据模式

有效点 mask 读完后，再写：

```text
0x31/0x71 = 0
```

切回真实数据模式。

写回 `0x71 = 0` 后，也必须重新读取 `0x31/0x2B`、`0x31/0x2C`、`0x31/0x6C`，再按新的描述符和长度读取 `0x32~0x34`。

## 6. 读取数据分布描述符

读 `0x31/0x2B` 获取数据分布描述符长度，再读 `0x31/0x2C` 获取描述符字符串。

例如：

```text
FnS_U16_1;Fn_U8_72
```

表示数据区排列为：

- 1 个 `uint16_t` 法向力合力
- 72 个 `uint8_t` 点阵值

再例如：

```text
Fn_F32_1;Ft_F32_1;Fd_U16_1;Px_U32_1
```

表示数据区排列为：

- 1 个 `float` 法向力
- 1 个 `float` 切向力
- 1 个 `uint16_t` 切向力方向
- 1 个 `uint32_t` 接近值

多字节数据按 MCU 小端格式返回。

例如 float 原始字节为：

```text
63 1E 1C 40
```

上位机按 little-endian IEEE 754 float 解析，约等于 `2.439`。

## 7. 读取真实数据总长度

读 `0x31/0x6C` 获取当前数据总长度。

后续读取 `0x32~0x34` 时，要按 `data_length_total` 分段读取：

- `0x32`：第 `0~254` 字节
- `0x33`：第 `255~510` 字节
- `0x34`：第 `511` 字节以后

如果数据总长度不超过 `255`，只读 `0x32` 即可。

## 8. 设置读取行列与降采样

如果是点阵传感器，可以通过 `0x31/0x6F` 和 `0x31/0x70` 设置希望读取的行列：

- `0x6F`：目标行数
- `0x70`：目标列数

`0x6F/0x70` 不允许写 `0`，也不能超过当前选择区域的最大行列。

如果设置的行列小于最大行列，MCU 会把原始最大矩阵做平均降采样，再返回给上位机。

例如原始是：

```text
24 x 20
```

设置成：

```text
12 x 10
```

返回的数据就是降采样后的 `12 x 10`。

注意：当前协议约定描述符仍按静态最大布局返回，不会因为 `0x6F/0x70` 降采样动态变化。实际降采样后没有写满的数据区会保持为 `0`。因此写 `0x6F/0x70` 后，也建议重新读取 `0x31/0x2B`、`0x31/0x2C`、`0x31/0x6C`。

## 9. 设置矩形补齐模式

`0x31/0x72` 控制真实数据是否返回矩形补齐格式：

- `0x72 = 1`：矩形补齐模式，默认推荐。返回 full 矩阵，无效点位置也保留，通常为 `0`。
- `0x72 = 0`：紧凑模式。返回时去掉无效点，只连续返回有效点数据。

注意：`0x71` 和 `0x72` 作用不同。

- `0x71 = 1`：返回有效点 mask，不返回真实压力数据。
- `0x72 = 0/1`：只影响真实数据模式下，点阵数据是 full 矩阵还是 valid 紧凑数据。

写 `0x72` 后，必须重新读取：

- `0x31/0x2B`
- `0x31/0x2C`
- `0x31/0x6C`

然后再按新的描述符和长度读取 `0x32~0x34`。

## 10. 紧凑模式下重新读取描述符和长度

如果使用 `0x72 = 0` 紧凑模式，描述符和数据长度会切换到 valid 紧凑数据格式。

例如原来 full 模式是：

```text
FnS_U16_1;Fn_U8_72
```

切到紧凑模式后可能变成：

```text
FnS_U16_1;Fn_U8_66
```

表示这个传感器原本 72 个矩阵点里有 6 个无效点，紧凑模式下只返回 66 个有效点。

## 11. 读取实时数据

最后按描述符和 `data_length_total` 读取 `0x32~0x34`。

上位机解析时不要写死数据格式，应该以 `0x31/0x2C` 返回的描述符为准。

读取真实数据前，必须先确认当前 `0x71` 为 `0`。

如果 `0x71` 为 `1`，`0x32~0x34` 返回的是有效点 mask，不是真实触摸数据。
